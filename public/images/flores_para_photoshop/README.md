## ✂️ Pasos Rápidos en Photoshop (1 minuto por imagen)

1. Abre cualquiera de los archivos `.png` o `.jpg` en Photoshop.
2. Si la capa está bloqueada como *Fondo*, haz doble clic sobre ella en el panel de capas para convertirla en *Capa 0*.
3. Ve al menú superior: **Selección > Gama de colores...** (Select > Color Range).
4. Con el cuentagotas, haz clic sobre el fondo verde claro. Ajusta la tolerancia (Fuzziness) a ~40-60 para seleccionar todo el verde.
5. Haz clic en **OK**.
6. Presiona la tecla **Suprimir (Delete)** para borrar el fondo verde.
7. Ve a **Archivo > Guardar como / Exportar como PNG** con transparencia.
8. Guarda el resultado con el nombre de destino en:
   ```
   public/images/flores/<nombre-exacto>.png
   ```

Una vez que guardes los archivos en `public/images/flores/`, la web los cargará de inmediato con recorte profesional sin fondos negros ni bordes desvanecidos.
